# Roadmap de aprendizado

1. FastAPI e rota `GET /health`.
2. Dados temporarios e rotas de personagens.
3. PostgreSQL, modelagem e persistencia.
4. CRUD de personagens.
5. Usuarios, autenticacao e autorizacao.
6. Magias, relacionamentos e filtros.
7. Frontend simples consumindo a API.

Cada etapa deve estar funcionando e compreendida antes de avancar para a proxima.
